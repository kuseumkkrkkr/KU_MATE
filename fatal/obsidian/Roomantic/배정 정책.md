2. 관심관 정의가 틀림

<프론트엔드>

- 세션 생성이 되는 매칭 시작 창에서 별표로 관심관 지정하는 부분 제거

- 홈화면에 관심 관 설정하기 버튼을 아래에 기숙사 찾기 버튼 아래에 추가

- 관심 관 설정 페이지에서 자신의 성별에 맞는 관심 관을 지정 후 저장

<기능 설명>

내가 매칭을 받을(타인이 세션을 생성하면 내가 표출됨) 기숙사 관을 미리 프로필에 등록해두어 타인에게 내가 노출되게 하는 것

<백엔드>

- 세션 생성 시 선택했던 관과 관심관이 일치해야 함, SQL 에도 가드레일 적용

- 세션 생성 시 선택하든, 관심관을 선택하든 반드시 동시에 반영됨 / 관심관을 먼저 선택한 경우 세션 생성 시 변경 불가

- 세션 생성을 먼저 하였든, 관심관을 먼저 선택하였든 지정된 경우 변경이 불가능하며(확정 시점부터 생활종료일까지) 예비매칭 기간, 메인 매칭 기간에만 각각 단 1회만 변경 가능함

- 최대 관 선택 제한 가드레일 역시 동일하게 관심관 등록에도 적용됨

- 룸메이트 메인 신청기간이 왔으나, 아직 생활방이 만들어지지 않은 경우 반드시 1개관을 지정하라는 알림 발송 및 매칭 풀에 등록되지 않음

- 메인 신청 기간에는 반드시 1개관으로 확정해야 하며, 그렇지 않을 경우 매칭 풀 자체에 등록되지 않음

- 메인 신청 기간 중 세션을 생성하거나, 관심관을 먼저 지정하든 동시에 반영됨
